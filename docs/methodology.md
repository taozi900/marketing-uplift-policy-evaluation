# 方法说明

## 1. 从随机邮件实验定义问题

主比较为男装邮件（T=1）与不发邮件（T=0），保留两组42,613条记录。原实验另有女装邮件组，本项目没有将两种邮件合并。

主结果 `Y=conversion`：活动后14天是否至少购买一次。每条记录的结果取0或1，策略效应的计数口径是新增购买人数，而非订单次数。

原始数据没有真实客户ID。以原CSV行序生成 `source_row_proxy` 关联划分和输出；保留属性相同的记录。原始审计发现6,562条额外整行相同记录，不能仅凭属性判断同一客户，独立记录假设仍有局限。

`02_lock_split.py` 在每个T组内按60%/20%/余量划分，种子20261014，不根据Y分层或选择样本。训练25,567、验证8,522、测试8,524。来源文件和划分CSV以SHA256关联。

## 2. 训练阶段的统计检查

- 03：两组购买率、差值、Wilson组内区间和Newcombe差值区间；属于初步训练结果。
- 04：实验前特征的标准化差异SMD，最大绝对值0.0218。0.1仅作描述性参考，不单独证明随机化有效或不存在混杂。
- 05：查看总体训练结果后新增探索 `newbie` 两层及历史消费原有七档；单项区间不提供九项同时覆盖，也不凭两组各自显著性判断异质性。
- 06：各组独立Beta-Binomial模型，主先验Beta(0.5,0.5)，敏感性Beta(1,1)，直接抽样200,000次；不是层级部分池化。可信区间在给定模型、先验和数据条件下解释，不能与频率学置信区间混用。

这些分析用于理解训练数据与形成假设。后续没有根据验证或测试效果搜索分层、特征、正则化或容量。

## 3. 排序模型

一个共享模型：`P(Y=1 | Z,T)`，采用带处理交互的L2 Logistic S-learner。

| 项目 | 实际实现 |
|---|---|
| 数值特征 | recency（距上次购买的月数）、log1p(history)，仅训练集拟合StandardScaler |
| 二元特征 | newbie、mens、womens |
| 类别特征 | zip_code、channel，训练集拟合OneHotEncoder、drop=first |
| 处理变量 | T及与recency、log_history、newbie的三项交互 |
| 模型 | C=1、lbfgs、max_iter=5000、tol=1e-8、无类别权重 |
| 结果 | 49次优化迭代；模型保存与重新载入检查通过 |

`history_segment` 与history重叠，主模型不再加入。原始行号和 `visit/conversion/spend` 不作为客户特征。`mens/womens` 表示历史购买品类；`channel` 表示历史购买渠道。

同一客户特征分别设置T=0和T=1（同步改变交互项），得到模型预测p0和p1。按p1排序表示优先选择发邮件情景下购买概率高的人；按p1-p0排序表示优先选择预测增量高的人。模型分数需要独立评价，不是已知的个体因果真值。

## 4. 四条选人规则

随机名单、history降序、p1降序、p1-p0降序。各策略均从相同客户集合选择 `K=floor(q*N)` 条；排序并列时按原始行号升序。随机规则使用种子20261014的一份固定排列，不代表所有随机名单的平均表现。

主容量q=20%，探索q=5%/10%/30%。验证集评价前记录规则及主要比较：20%下增量排序减购买概率排序。验证后没有选择赢家，测试时沿用相同四条规则、模型、容量和比较。

## 5. IPW策略增量

在主分析的两个随机组中，采用已知处理概率e=0.5。对每位合格客户计算：

```text
s_i = T_i * Y_i / 0.5 - (1-T_i) * Y_i / 0.5
G(a) = mean(a_i * s_i) * 10,000
```

`a_i` 是该策略是否选中记录i的0/1标记。G(a)估计相对整批客户均不发邮件时，按该策略仅给选中客户发邮件的新增购买人数，每万名合格客户归一化。

客户原实验是否被随机分配到邮件组，与策略是否选中是两个不同变量。离线评价使用全部实验记录及随机分配权重；数据没有送达记录，不能把分配到邮件组理解为已确认送达。

主要策略差值直接使用同一客户上的贡献：

```text
D = mean((a_uplift - a_p1) * s_i) * 10,000
```

同一客户被两条策略同时选中或同时不选中，其差值贡献为0。两张名单不相同且实际购买的记录为比较提供事件信息，主容量测试集中这样的购买记录只有15条。

## 6. 区间与解释

策略评价使用5,000次配对Bootstrap、种子20261016：在T组内分别重采样记录，保持两组样本量；同次重采样用于所有策略，保留策略间相关性。区间为逐项百分位95%。

区间以本次固定训练模型、分数和原始名单为条件，不重训、不重新排序，不涵盖整个建模或选择流程的不确定性。各策略和各容量的区间不是同时覆盖区间。事件稀疏时非参Bootstrap可能不稳定或退化；增加重复次数不能生成更多独立购买事件。

主差值区间包含0说明证据不足以确定优劣，不等于效果相同。不能用单策略区间是否跨0、区间是否重叠或点估计大小替代配对策略比较。
