**营销活动增量评估与客户触达策略：项目数据**

数据集：Kevin Hillstrom 的 MineThatData E-Mail Analytics Challenge（2008年公开挑战）。数据来自公开历史营销实验，项目属于公开数据个人研究。

来源与获取：

- [TFDS 官方数据说明](https://www.tensorflow.org/datasets/catalog/hillstrom)
- [原发布者挑战页面](https://blog.minethatdata.com/2008/03/minethatdata-e-mail-analytics-and-data.html)
- [scikit-uplift 维护者加载源码与镜像说明](https://www.uplift-modeling.com/en/latest/_modules/sklift/datasets/datasets.html#fetch_hillstrom)
- [本次实际下载的压缩 CSV](https://hillstorm1.s3.us-east-2.amazonaws.com/hillstorm_no_indices.csv.gz)

`hillstrom_original.csv.gz`为镜像的原始压缩文件。`hillstrom.csv`仅直接解压，没有删行、补值或改列名。`source_manifest.json`记录下载地址、时间、哈希、字段及检查结果。

本次检查结果：64,000行、12字段、缺失值总数0。压缩文件MD5与维护者记录`a68a81291f53a14f4e29002629803ba3`一致。购买/访问/消费结果之间的三项逻辑检查均未发现冲突。以上是数据完整性检查，不是模型效果或随机化有效性证明。

| 实验组 | 实际记录数 |
|---|---:|
| 男装邮件 `Mens E-Mail` | 21,307 |
| 女装邮件 `Womens E-Mail` | 21,387 |
| 不发邮件 `No E-Mail` | 21,306 |
| 合计 | 64,000 |

每行代表一名实验客户的属性与实验后结果。官方说明为过去12个月购买过的客户随机分为三组，观察活动后两周结果。没有真实客户ID，不按属性整行相同擅自去重。

| 字段 | 说明 | 项目用途 |
|---|---|---|
| recency | 距上次购买的月数 | 实验前特征 |
| history | 过去一年消费金额 | 实验前特征 |
| history_segment | 历史消费金额分组 | 与history重叠，主模型不同时堆入 |
| mens | 过去是否购买男装 | 实验前品类特征，不是客户性别 |
| womens | 过去是否购买女装 | 实验前品类特征，不是客户性别 |
| zip_code | Urban/Surburban/Rural城乡类别 | 实验前特征，原文保留Surburban拼写 |
| newbie | 过去12个月新获取客户标记 | 实验前特征 |
| channel | Web/Phone/Multichannel历史购买渠道 | 实验前特征，不能当随机分配的获客渠道 |
| segment | 邮件实验分配组 | 生成处理变量T |
| visit | 活动后是否访问 | 结果变量，禁止作实验前特征 |
| conversion | 活动后是否购买 | 主结果Y，禁止作特征 |
| spend | 活动后消费金额 | 金额结果，禁止作实验前特征 |

为了保持与事先方案一致，主分析采用男装邮件与不发邮件两组，共42,613条；女装邮件保留用于后续扩展。原始文件始终保留完整三组。
