**结果查看规则**

- 全数据可以检查字段、类型、缺失、编码、来源、分组人数和结果逻辑冲突。
- 探索分层购买率、交互、金额长尾和模型选择主要使用训练集。
- 验证集用于比较预先提出的方案并冻结策略。新增尝试要记入实验日志，避免无限次调参。
- 最终测试集的结果在方案冻结后集中评价，不因成绩不理想再调整分层、特征、容量或模型。
- 总体ATE、贝叶斯评估可以在训练/验证阶段形成初步判断；最后在保留测试集报告预定义效应与名单比较。
- 有购买概率预测，不代表掌握个体真实因果效应。增量排序的价值要在留出集比较。
- 若增量策略优势证据不足，结论可以是保留简单策略或扩大实验。结果好看不是完成标准。
